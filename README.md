# Voxel Sandbox

一个使用 C++17 和 raylib 5.5 的体素沙盒游戏，类 Minecraft 风格。

## 环境搭建

### 1. 下载 MinGW-w64 (g++)

从 GitHub 下载 MinGW-w64（x86_64-posix-seh）：

```
https://github.com/niXman/mingw-builds-binaries/releases
```

解压到 `D:\mingw64`，将 `D:\mingw64\bin` 添加到系统环境变量 PATH：

```
Windows 搜索框 -> 高级系统设置 -> 环境变量 -> 系统变量 -> Path -> 编辑 -> 新建
```

验证：

```
g++ --version
```

### 2. 下载 raylib

从 GitHub 下载 raylib 5.5 MinGW-w64 版本：

```
https://github.com/raysan5/raylib/releases/tag/5.5
```

下载 `raylib-5.5_win64_mingw-w64.zip`，解压到 `D:\raylib\raylib-5.5_win64_mingw-w64`。

将 `D:\raylib\raylib-5.5_win64_mingw-w64\include` 添加到系统环境变量 PATH，使 `where raylib.h` 能定位到。

或者设置环境变量：
```
搜索 -> 高级系统设置 -> 环境变量
新建系统变量：
    变量名: RAYLIB_DIR
    变量值: D:\raylib\raylib-5.5_win64_mingw-w64
```

### 3. 编译

```
cd 项目目录
build.bat
```

生成 `game.exe`，双击运行。

### 背包界面

打开背包（E）后，左侧显示背包和快捷栏，右侧是合成网格。

| 操作 | 效果 |
|------|------|
| 左键点击物品 | 拿起/交换 |
| 右键点击物品 | 取一半 / 放一个 |
| 右键拖拽 | 经过每个格子放一个 |
| ESC | 关闭背包 |

### 生存机制

- **生命值**：屏幕左上红色方块，共 10 颗心（20 HP）
- **饱食度**：屏幕左上黄色方块，消耗后自动回血
- **坠落伤害**：超过 3 格高度掉落会受到伤害
- **饥饿**：饱食度随时间缓慢消耗，归零后持续扣血
- **挖掘**：不同方块需要对应等级的工具才能开采（铁镐挖钻石，石镐挖铁矿等）
- **镐子**：对石头、圆石、矿石、熔炉等石质方块有加速效果

### 合成

合成系统支持 2x2（手工艺）和 3x3（工作台）两种规格。

右键工作台方块打开 3x3 合成网格。

部分配方：

| 产物 | 材料 |
|------|------|
| 木板 | 原木 x1 |
| 木棍 | 木板 x2（竖排） |
| 木镐 | 木板 x3（顶横排）+ 木棍 x2（竖排） |
| 石镐 | 圆石 x3（顶横排）+ 木棍 x2（竖排） |
| 铁镐 | 铁锭 x3（顶横排）+ 木棍 x2（竖排） |
| 金镐 | 金锭 x3（顶横排）+ 木棍 x2（竖排） |
| 钻石镐 | 钻石 x3（顶横排）+ 木棍 x2（竖排） |
| 工作台 | 木板 x4 |
| 熔炉 | 圆石 x8 |
| 箱子 | 木板 x8 |

### 熔炉

冶炼工具。上方放矿石，下方放燃料（煤炭/木炭），等待约 8 秒产出：

| 输入 | 燃料 | 输出 |
|------|------|------|
| 粗铁 | 煤炭 | 铁锭 |
| 粗金 | 煤炭 | 金锭 |

### 箱子

27 格容器，放置后右键打开，可存入任意物品。破坏箱子时内部物品会掉落在地上。

## 文件结构

| 文件 | 说明 |
|------|------|
| `main.cpp` | 主循环、游戏状态管理、输入处理 |
| `block.h` | 方块定义、纹理索引、硬度/等级/掉落表 |
| `chunk.h/cpp` | 区块数据与网格构建（面剔除） |
| `world.h/cpp` | 世界管理、地形生成（噪声高度图+矿物分布） |
| `noise.h/cpp` | 分形噪声（FBM）用于地形 |
| `player.h/cpp` | 玩家物理、碰撞、挖掘、拾取 |
| `item.h` | 物品类型、工具等级、效率 |
| `inventory.h` | 物品栏（24格：8热键+16背包） |
| `crafting.h/cpp` | 合成系统（2x2/3x3配方） |
| `chest.h/cpp` | 箱子容器（27格） |
| `furnace.h/cpp` | 熔炉冶炼（输入/燃料/输出） |
| `renderer.h/cpp` | 渲染：天空/昼夜/HUD/背包/箱子/熔炉/3D物品 |
| `texture_atlas.h/cpp` | 纹理图集（程序化生成） |
| `drop.h/cpp` | 掉落物物理、碰撞、拾取 |
| `mob.h/cpp` | 生物框架（基础碰撞） |

## 技术实现

- **渲染**: raylib Mesh 用于区块，rlgl 用于掉落物 3D 立方体，RenderTexture 离屏渲染物品 3D 预览
- **纹理**: 64x256 图集，代码绘制每像素，4 列 x 16 行共 64 槽
- **世界**: 区块 16x64x16，确定性随机种子，面剔除只渲染可见面
- **字体**: SimHei 加载 CJK 全范围，支持中文显示
